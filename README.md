# ACR4 🤖

An Android application developed as part of an **Interdisciplinary Project (IDP)** at the Military Institute of Science and Technology (MIST). ACR4 serves as the mobile control and monitoring interface for an **Autonomous Cleaning Robot**.

---

## About

ACR4 is the companion Android app for a hardware-based autonomous cleaning robot. The app provides a user interface to communicate with and control the robot, enabling remote operation and monitoring from an Android device.

---

## Tech Stack

- **Language:** Java (100%)
- **Platform:** Android
- **Build System:** Gradle
- **IDE:** Android Studio / IntelliJ IDEA

## Getting Started

**Requirements**
- Android Studio (latest stable)
- Android device or emulator (API 21+)

**Steps**

1. Clone the repo:
```bash
git clone https://github.com/QZenQ/ACR.git
```

2. Open the project in **Android Studio**

3. Let Gradle sync complete

4. Run on a connected Android device or emulator

---

## Context

This project was developed as part of the Interdisciplinary Project (IDP) course at **MIST (Military Institute of Science and Technology)**, Dhaka, Bangladesh. The full system includes both the robot hardware and this Android app as its control interface.
